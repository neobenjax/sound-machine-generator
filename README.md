# Sound Machine Generator

A browser-based procedural sound composer and Web Audio code generator built with **Tone.js** and the **Native Web Audio API**.

- Compose, layer, and tune tactile card foley & game sound effects in real time.
- Inspect live **Tone.js** and **Vanilla Web Audio API** code instructions.
- Save custom sounds to `localStorage`, export/import JSON libraries, and test click/swipe/programmatic triggers in the Integration Playground.
